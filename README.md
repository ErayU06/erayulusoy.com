# erayulusoy.com

Source of [erayulusoy.com](https://erayulusoy.com): the website of Eray Ulusoy, web designer and software engineer offering corporate websites, business applications and cloud services.

The site is a fast static site in English (`/`) and Turkish (`/tr/`). Visitors whose browser language is Turkish are sent to the Turkish page automatically; everyone can switch with the EN / TR toggle. Unknown URLs get a bilingual 404 page.

## Structure

| Path | What it is |
| --- | --- |
| `src/template.html` | Page template shared by both languages |
| `src/404.html` | Bilingual "page not found" template |
| `src/build.py` | All page text (`EN`, `TR` and `NOT_FOUND`), SEO data and the build script |
| `src/assets/` | Styles, scripts, self-hosted fonts and the app icon |
| `src/_headers` | Security headers (CSP, HSTS and others) applied by Cloudflare |
| `src/robots.txt`, `src/sitemap.xml` | Search engine files |
| `src/security.txt` | Published at `/.well-known/security.txt` |
| `wrangler.jsonc` | Cloudflare Workers config (worker name, `dist/` as assets, 404 handling) |
| `.github/workflows/deploy.yml` | Builds on every push and pull request, deploys `main` to Cloudflare |
| `dist/` | The built site. Generated by `src/build.py`; do not edit by hand. |

## Editing text

1. Change the wording in `src/build.py`. `EN` holds the English copy; `TR` overrides it with the Turkish copy. Every key is used by `src/template.html` as `{{key}}`.
2. Build and preview locally:

   ```bash
   python3 src/build.py
   python3 -m http.server -d dist 8000   # open http://localhost:8000
   ```

3. Commit and push to `main`. The site deploys automatically (see below).

When the content changes, also update `<lastmod>` in `src/sitemap.xml`.

## Deploying

The site runs on Cloudflare Workers static assets (worker `ancient-silence-129c`, domains `erayulusoy.com` and `www.erayulusoy.com`).

Every push to `main` runs `.github/workflows/deploy.yml`, which builds the site and runs `wrangler deploy`. Pull requests are built and checked but not deployed.

One-time setup, in the GitHub repo under **Settings → Secrets and variables → Actions**:

- `CLOUDFLARE_API_TOKEN`: create it in the Cloudflare dashboard under **My Profile → API Tokens → Create Token → Edit Cloudflare Workers** template.
- `CLOUDFLARE_ACCOUNT_ID`: shown on the Cloudflare dashboard's **Workers & Pages** overview.

Until both secrets exist, the workflow still builds but skips the deploy step.

To deploy by hand instead: `python3 src/build.py && npx wrangler deploy`.

## Contact form

The form posts to [Formspree](https://formspree.io) (form ID in `FORMSPREE_ID` in `src/assets/main.js`), which emails enquiries to contact@erayulusoy.com. If the ID is ever removed, the form falls back to asking visitors to email directly.
